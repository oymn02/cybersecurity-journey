# Python security tools

Small, transparent utilities for learning security concepts and automating repeatable tasks.

Project ideas:

- HTTP header and TLS configuration checker for a user-supplied authorized endpoint.
- Log parser for synthetic sample data.
- Hashing and file-integrity utility.
- Simple network inventory script for a private lab.

Every tool should state its intended use, limitations, dependencies, and safe scope. Include tests and example input/output where practical.
