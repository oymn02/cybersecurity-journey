# Fundamentals

Core notes that support later security work.

Planned topics:

- Networking: TCP/IP, DNS, ports, routing, TLS.
- Linux: shell, files, permissions, processes, services.
- Web: HTTP, cookies, sessions, authentication, APIs.
- Python: data types, files, requests, parsing, testing.

Each note should explain the concept, show a small safe example, and link to reliable references.
