# Documentation standards

This repository values reproducible work, precise claims, and safe testing.

## Lab write-up checklist

- State the objective and learning outcome.
- Identify the platform and the authorized scope.
- Describe the relevant technical concepts.
- Record the method in enough detail to understand the reasoning.
- Separate observed facts from assumptions.
- Explain impact and realistic mitigations.
- Note limitations and unanswered questions.
- Cite the original documentation or learning resource.

## Safety rules

- Test only systems you own, intentionally vulnerable training environments, or systems for which you have explicit authorization.
- Do not publish credentials, tokens, personal data, or private customer information.
- Use synthetic data in examples.
- Avoid instructions that could be mistaken for authorization to test a real third-party target.
- Keep experiments isolated and document the environment.

## Writing style

Prefer concise explanations, commands with context, sanitized outputs, and diagrams where they add clarity. A small experiment with a careful explanation is more valuable than an unsupported claim.
