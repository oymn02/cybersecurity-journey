# AI security

Research and practical assessments of security risks in applications built with large language models (LLMs).

## Topics

- Prompt injection, including indirect prompt injection.
- Sensitive information disclosure.
- Insecure output handling.
- RAG retrieval boundaries and access control.
- Tool and agent permissions.
- Evaluation, monitoring, and defense in depth.

## Assessment format

For each assessment, document:

1. System model and trust boundaries.
2. Assets, actors, and security objectives.
3. Threat scenarios and assumptions.
4. Safe test cases and observed behavior.
5. Risk and practical impact.
6. Mitigations and residual risk.
7. References.

Use only owned systems, approved test environments, or explicit authorization. Do not use real private data in experiments.
